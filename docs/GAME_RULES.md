# FanBall 경기 종료 규칙

작성일: 2026-11-05  
적용 규칙: 2026 KBO 정규시즌의 12회 제한을 따르는 FanBall 샘플 시뮬레이션

## 종료 순서

1. 기본 경기는 9이닝이다. 9회 초 종료 시 홈팀이 앞서 있으면 홈팀 승리로 끝내고 9회 말은 진행하지 않는다.
2. 9회 초 종료 시 동점이거나 원정팀이 앞서 있으면 9회 말까지 진행한다. 홈팀이 9회 말 공격에서 리드를 잡으면 그 즉시 끝내기 승리다.
3. 9회 말까지 동점이면 10회로 간다. 연장에서도 같은 방식으로 공격과 수비를 이어간다. 원정팀이 초 공격을 마친 뒤 홈팀이 이미 앞서 있으면 말 공격은 생략하고 홈팀 승리로 종료한다. 홈팀은 말 공격 중 리드를 잡으면 끝내기로 승리한다.
4. 12회 말까지 마쳤을 때 점수가 다르면 앞선 팀의 승리다. 12회 말 종료 후에도 동점이면 무승부로 종료한다. 13회는 시작하지 않는다.

홈팀이 12회 초 종료 뒤 앞서면 12회 말 없이 종료하고, 원정팀이 12회 초 앞선 채로 12회 말을 막으면 원정팀 승리다. 따라서 `12회 종료 무승부`는 12회 말까지 실제 진행한 뒤에도 동점인 경기만을 뜻한다.

## KBO 규정 근거 및 적용 범위

KBO의 2026 시즌 규정 개정 발표는 연장 승부치기를 10회부터 12회까지만 진행하고 그 이후에는 무승부 처리한다고 명시한다. FanBall은 이 상한과 무승부 처리를 사용한다. 2025 정규시즌은 연장 11회까지였으므로, 규칙 스냅샷은 해당 경기 날짜의 시즌 규정 버전을 사용해야 한다. 현재 샘플 경기 엔진의 최대 이닝 설정은 12회다.

## 엔진 상태

- 홈팀 리드 여부만으로 9회 초를 시작하기 전에 종료하던 버그를 제거했다.
- 정규 9이닝과 연장 10~12회 종료 조건을 구현했다.
- 12회 말 동점 종료 시 `tiebreak` 결과에 `12회 종료 무승부`를 기록하고 결과 화면에 승리팀/무승부를 표시한다.
- 샘플 결과의 실제 기록 집계(투수 승패, 자책점 등)는 별도 보완 대상이다. 여기서 말하는 승리팀은 점수에 따른 경기 결과다.

## 변경 기록

- 2026-11-05: 최대 12회 및 12회 종료 무승부를 명확히 하고, 야구의 끝내기·홈팀 리드·초/말 종료 규칙을 반영.
