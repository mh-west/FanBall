# 실제 KBO 기록 공급원 검토

확인일: 2026-11-10
결론: **아래 사이트들에서 허가 없이 기록을 자동 수집하지 않는다.** 실제 기록은 공식 허가(서면 동의 또는 공식 API·데이터 계약)를 받은 뒤 `docs/ORCHESTRATOR_DESIGN.md`의 데이터 공급원 인터페이스로 연결한다. 그 전까지는 샘플 명단(`provider='demo'`)만 쓴다.

이 문서는 각 페이지에 적힌 내용을 요약한 것이며 법률 자문이 아니다.

| 출처 | 확인한 곳 | 내용 | 판단 |

## 다음 확인 경로

- KBO 영상·사업 문의처로 KBOP(kbop03@koreabaseball.or.kr)가 안내되어 있다. 기록 데이터 이용 가능 여부와 조건(비용, 범위, 표기 의무)을 문의한다.
- KBO 공식 기록 업체인 스포츠투아이의 데이터 제공 조건도 함께 확인한다.
- 해외 스포츠 데이터 API(KBO 지원 여부·약관)는 별도로 비교한다.
