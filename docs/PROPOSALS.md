# 제안 보관함 (아직 구현 전)

사용자와 이야기했지만 아직 만들지 않은 기능의 제안입니다. 구현을 시작하기 전에 사용자와 다시 정합니다. 정해지면 `docs/DECISIONS.md`로 옮기고 여기서는 "결정됨"으로 표시합니다.

## 1. 중계투수(불펜) — 2026-11-12 사용자 승인(진행하기로 함)

지금은 팀마다 선발투수 한 명이 경기 끝까지 던진다.

1. **선발 피로도**: 투구 수가 늘면 선발의 볼넷·피안타 확률이 조금씩 오른다. 예: 75구까지 변화 없음, 그 뒤 15구마다 피안타·볼넷 배율 +4% 정도, 100구를 넘으면 크게 오름. 숫자는 가정값으로 문서에 적는다.
2. **불펜 3명**: 팀마다 필승조 2명 + 마무리 1명. 나무위키 투수 문서에서 피안타율·볼넷·삼진율·구종·구속을 읽는다(선발 10명과 같은 방식, 출처 URL 저장).
3. **교체 시점**:
   - 기본은 자동 교체: 투구 수(예: 95구 전후)나 한 이닝 실점(예: 3점 이상), 6회 이후 위기 상황.
   - 동점·접전인 7회 이후에는 수비 쪽 팬 투표에 "투수 교체" 선택지를 넣는다(타석 전 투표에만).
   - 마무리는 9회 3점 차 이내 리드에 등판.
4. **AI 대결**: AI 감독은 기대 실점(RE24)으로 교체를 판단한다.
5. **화면**: 투수 이름 카드에 투구 수와 교체 기록, 경기 결과에 투수 기록(이닝·피안타·실점·볼넷·삼진).

추천 순서: 1(피로도) → 2(불펜 데이터) → 3(자동 교체) → 팬 투표 교체 → 투수 기록 화면.

### 불펜 3명을 누구로 정할지 (2026-11-12 추가)
- **자동 초안**: 나무위키 각 투수의 2026 시즌 기록에서 팀별로 세이브 1위 = 마무리, 홀드 1·2위 = 필승조. 실제 2026 불펜 구성을 그대로 따르므로 우완만 셋일 수도 있고 좌완·사이드암이 섞일 수도 있다.
- **사람이 고친다**: 초안 표(팀·이름·역할·투구 손·팔 각도·세이브/홀드·근거 URL)를 사용자에게 보여 주고 바꿀 선수를 반영한다. 결과는 `data/bullpen-2026.json`처럼 사람이 고칠 수 있는 파일로 둔다.
- **투구 손과 팔 각도**: 손(우투/좌투)은 나무위키 명단의 투타, 팔 각도(오버핸드·스리쿼터·사이드암·언더핸드)는 선수 문서의 설명에서 읽는다(고영표처럼 사이드암·언더핸드는 문서에 대개 적혀 있다).
- **좌우 상성과 함께 넣어야 의미가 있다**: 지금 엔진은 좌우를 확률에 쓰지 않는다. 좌완 원포인트·사이드암 기용이 의미를 가지려면 좌우 상성(같은 손이면 타자 불리)을 함께 넣는다. 사이드암·언더핸드는 같은 손 타자에게 더 강하고 반대 손 타자에게 더 약하게(상성 폭을 크게) 둔다.
- **교체 때 상대 타자 고려**: 자동 교체는 다음 타자들의 좌우를 보고 그에 맞는 불펜(좌타 연속이면 좌완)을 먼저 고른다. 팬 투표 교체에서는 불펜 투수별로 투구 손·팔 각도·다음 세 타자와의 상성을 보여 준다.

엔진 결과가 바뀌므로 엔진 버전을 올리고 진행 중인 서버 경기가 없을 때 배포한다.

## 2. 주력 — 제안 2026-11-12

사용자 의견: 기록만으로 판단하기는 이르다. 예) 김도영은 리그 최상급 주력이지만 햄스트링 부상 관리로 잘 뛰지 않는다.

1. **두 값으로 나눈다**
   - 주력(얼마나 빠른가): 5단계(1 느림 ~ 5 매우 빠름), 기본 3.
   - 도루 성향(얼마나 자주 뛰는가): 3단계(적음·보통·많음).
2. **주력 등급은 사람이 정한다**: 팀별 초안을 만들어 사용자가 고친다. 초안 참고값은 3루타 비율, 내야안타, 병살 비율, 수비 위치(중견수·유격수 가중). 도루 기록은 도루 성향 초안에만 쓴다. 기록과 실제가 다른 선수(김도영 등)는 직접 조정한다.
3. **주력이 쓰이는 곳**(효과 큰 순서)
   - 단타 때 1루 주자 3루 진루, 2루 주자 홈 득점 확률
   - 병살타 확률(빠른 타자는 감소)
   - 내야안타·번트 안타 확률
   - 희생플라이 때 3루 주자 득점 확률
4. **도루 성향이 쓰이는 곳**: 나중에 추가할 "도루" 공격 작전의 시도 빈도. 성공률은 주자 주력·투수(퀵모션)·포수에 따른다.
5. **데이터 보관**: `data/runner-speed.json` 같은 사람이 고칠 수 있는 파일에 선수별 등급과 근거 메모를 둔다.

추천 순서: 등급 초안 표 작성 → 사용자 검토 → 주루·병살 보정 → 도루 작전.
