## 실제 명단을 아직 넣지 않은 이유

KBO는 2026년 등록 선수 공시와 구단별 선수 명단 파일을 제공한다. 다만 해당 보도자료에는 KBO 뉴스·사진의 무단 전재와 재배포를 금지한다는 고지가 있다. 데이터 화면을 조회할 수 있다는 사실만으로 정적 복제·재배포·상업 사용 허가가 생기지는 않는다. 실제 선수 명단, 기록, 로고와 사진을 앱에 넣기 전에는 사용 범위와 라이선스를 확인한다.

- KBO 2026 등록선수 공시: https://www.koreabaseball.com/MediaNews/Notice/View.aspx?bdSe=11831
- 현재 개발용 8개 구단의 선수명은 `팀 샘플 타자 1`처럼 가상으로 만들고, 타격 기록과 투수 능력도 임의의 화면 테스트 값으로만 둔다.
- 두산·KIA에 이미 보이는 실명도 현재 MVP의 기록값을 공식 KBO 기록이라고 간주할 수 없다.
- 향후 허가된 `DataProvider`가 팀별 실제 선수단과 경기 전날 기준 기록을 공급하면 가상 명단을 교체한다.

## 샘플 매치업과 관리자 검증

- 공개 화면의 기본 데모 매치업은 두산- KIA다. 일정 공급원에 연결된 실제 경기 일정이라는 뜻이 아니다.
- `?admin=1` 경기 센터에서 원정팀과 홈팀을 각각 10개 구단 중 선택해 작전 화면을 검증할 수 있다. 같은 팀을 양쪽에 놓을 수 없다.
- 각 팀 팬은 자기 응원팀이 공격 중이면 공격 선택지만, 수비 중이면 수비 선택지만 본다. 응원팀이 현재 매치업에 없으면 투표 불가 안내를 본다.
- 이 관리자 설정은 단일 브라우저 샘플 매치에만 적용한다. 실제 일정 선택과 여러 팬의 투표 집계는 서버 구현 이후 연결한다.
